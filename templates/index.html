Week 2 Goal
Rough target for this lab: Build a Flask web app that takes the circuit parameters, computes the BJT DC bias (VB, VE, VC, VCE, IB, IC, IE) for a common-emitter amplifier using fixed, emitter, or voltage-divider bias, and displays the results. All equations live in dc_bias.py.
