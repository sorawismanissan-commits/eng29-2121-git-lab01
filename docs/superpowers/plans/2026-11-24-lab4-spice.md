## Technical Requirements (เพิ่มเติมจากผู้ใช้ — ยืนยันว่าปฏิบัติตั้งแต่ Task 1)

ข้อกำหนดเหล่านี้เป็นข้อบังคับและได้ถูกออกแบบ/ทดสอบไว้แล้วในโค้ดปัจจุบัน:

1. **External Process (`subprocess.run`)**
   - เรียก `ngspice_con` ด้วย argument แบบ list เท่านั้น: `[ngspice, "-b", "circuit.cir"]`
   - ห้ามใช้ `shell=True` เด็ดขาด
   - ต้องกำหนด `timeout` ชัดเจน (ค่าเริ่มต้น 15 วินาที)
   - แยก working directory ตาม `run_id` ทุกครั้ง: `instance/spice_runs/<run_id>/`
   - ใช้ `capture_output=True, text=True, encoding="utf-8", errors="replace"`

2. **Batch Run & Netlist**
   - ใช้ `ngspice -b circuit.cir` และ `.control` + `wrdata` ตาม analysis ที่เลือกเท่านั้น
   - `.op` → `op.csv`, `.ac` → `ac.csv`, `.tran` → `tran.csv`; ห้ามอ่านไฟล์ข้าม analysis
   - ห้ามผสมบล็อก `.control ... .endc` กับ batch directive อื่นโดยไม่ทดสอบกับ ngspice 47 ก่อน
   - รูปแบบนี้ทดสอบแล้วกับ ngspice 47 (`ngspice_con -b`)

3. **Input Validation**
   - ตรวจว่าเป็นตัวเลข, มีหน่วยถูกต้อง เป็นค่าบวก และอยู่ในขอบเขตก่อนสร้าง netlist
   - ได้แก่ `vin_amp_mV > 0`, `vin_freq_Hz > 0`, `0 < ac_start_Hz < ac_stop_Hz`, `1 ≤ ac_ppd ≤ 100`, `0 < tran_step_s < tran_stop_s`, `rl_kohm > 0`
   - ห้ามส่งค่าจากฟอร์มเข้า command หรือ solver โดยตรง — `app.py` แปลงหน่วยเป็น SI ก่อนส่งเข้า `SpiceRequest`

4. **Result Parsing & Separation of Concerns**
   - `app.py`: รับ/ตรวจ request, แปลงหน่วย, ส่งงานให้ engine และ render ผลเท่านั้น
   - `spice_engine.py`: engine adapter — สร้าง netlist, รัน solver, parse ไฟล์ผลเป็น array/list ของตัวเลขพร้อมหน่วย, เก็บ artifacts
   - `dc_bias.py`: คงเป็น Analytical reference เดิม ห้ามแก้สมการ และแสดงแยกจาก SPICE พร้อม provenance เสมอ
   - Frontend: แสดง SVG ที่ render บนเซิร์ฟเวอร์ (`spice_plots.py`) ห้ามคำนวณแกนฟิสิกส์หรือวาดกราฟใหม่ใน browser

5. **Strict Error Handling**
   - ไม่พบ solver / run failed / output ว่าง / timeout / input ผิด → คืนสถานะ Error พร้อม `kind`, `message`, `run_id`
   - สร้าง `run_dir` และ `meta.json` ก่อนเรียก solver และเขียน status สุดท้ายใน `finally` เสมอ
   - ห้ามคืนกราฟหรือตารางเก่าพร้อมสถานะ Success เด็ดขาด; หน้าเว็บต้องไม่แสดง `sim-plot` เมื่อ run ล้มเหลว

import json
import subprocess
import tempfile
import unittest
from pathlib import Path
from unittest.mock import patch

from spice_engine import SpiceError, SpiceRequest, run_ngspice


class RunTests(unittest.TestCase):
    def test_run_dc_with_real_ngspice(self):
        if not find_ngspice_available():
            self.skipTest("ngspice_con not available in this environment")
        with tempfile.TemporaryDirectory() as tmp:
            result = run_ngspice(request("dc"), runs_root=Path(tmp))
            self.assertEqual(result["status"], "Success")
            self.assertEqual(result["analysis"], "dc")
            self.assertAlmostEqual(result["dc"]["ic_mA"], 1.2288, delta=0.05)
            self.assertAlmostEqual(result["dc"]["vce_V"], 8.0589, delta=0.1)
            self.assertTrue((Path(tmp) / result["run_id"] / "meta.json").exists())
            self.assertTrue((Path(tmp) / result["run_id"] / "circuit.cir").exists())

    def test_timeout_keeps_run_dir_and_meta(self):
        with tempfile.TemporaryDirectory() as tmp:
            with patch("spice_engine.subprocess.run", side_effect=subprocess.TimeoutExpired("ngspice", 1)):
                with self.assertRaises(SpiceError) as ctx:
                    run_ngspice(request("dc"), runs_root=Path(tmp))
            err = ctx.exception
            self.assertEqual(err.kind, "timeout")
            self.assertIsNotNone(err.run_id)
            meta = Path(tmp) / err.run_id / "meta.json"
            self.assertTrue(meta.exists())
            self.assertEqual(json.loads(meta.read_text(encoding="utf-8"))["kind"], "timeout")

    def test_process_error_is_not_success(self):
        fake = subprocess.CompletedProcess(["ngspice"], 1, "", "singular matrix")
        with tempfile.TemporaryDirectory() as tmp:
            with patch("spice_engine.subprocess.run", return_value=fake):
                with self.assertRaises(SpiceError) as ctx:
                    run_ngspice(request("dc"), runs_root=Path(tmp))
            self.assertEqual(ctx.exception.kind, "process_error")
